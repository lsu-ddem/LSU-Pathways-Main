## Development

This website uses Hugo (Version 0.83.1) to generate a static website which is then built and deployed using Netlify. 


## Project Structure

All pages for the LSU Pathways Website are made as MARKDOWN (.md) files and can be found in the "content" folder. The home page is divided into multiple .md files in the content/home/ directory. These files have a large amount of demo code at the top of them and can appear to be unused files at first look. Make sure to scroll down to see the page content.
